# Demo

Space Apps rules: video up to 30 seconds (with English subtitles) OR a slide
deck up to 7 slides (including title slide, in English). Host externally
(YouTube, Drive, GitHub, etc.) — you cannot upload the file directly to the
Space Apps site.

Slide deck should cover, in this order:
1. Title slide — team name, challenge selected
2. Problem (why microgravity fire is uniquely dangerous)
3. Approach (data → features → model → risk engine)
4. Key result (one plot, one number)
5. ICS/SCADA security architecture (the diagram)
6. Impact / what this enables for real habitats
7. Team members / links (paper, repo)

Put the final exported video/slides/link in this folder or note the external
link here once ready.
