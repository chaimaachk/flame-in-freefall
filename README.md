# Flame in Freefall

AI-Powered Fire Safety Insights from Microgravity Combustion Data

NASA Space Apps Challenge 2026

## Objective

Analyze NASA microgravity combustion data to identify combustion-risk
patterns and design an AI-assisted fire safety and secure control architecture.

## Core Pipeline

```
NASA Dataset
    ↓
Data Preprocessing
    ↓
Combustion Feature Extraction
    ↓
ML Risk Prediction
    ↓
Risk Score
    ↓
Safety Decision
    ↓
ICS/SCADA Simulation
    ↓
Cybersecurity Monitoring
```
